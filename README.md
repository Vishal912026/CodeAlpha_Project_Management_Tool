# Project Management Tool

## Live Demo
- Frontend: https://codealpha-project-management-tool.netlify.app
- Backend: https://codealpha-project-management-tool-gomj.onrender.com

This is my Task 3 project for CodeAlpha Full Stack Development Internship. It's a simple project management app where you can create projects, add team members, create tasks, assign them to people, and comment on tasks. Basically a mini Trello clone.

## Features
- Register/Login with JWT
- Create projects and add members by email
- Create tasks, set priority, assign to a member
- Move tasks between To-Do, In-Progress, Done
- Comment on tasks

## Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB Atlas

## What I learned
Built this after Task 1, so I reused a lot of the backend structure (auth, JWT). New things I learned here were handling nested data (comments inside tasks) and role-based access for project members.
